# Ventures AI

Ask questions about YC-backed startups. Answers are retrieved via hybrid (keyword + vector)
search over the YC-OSS company database and generated by the LLM you pick in the profile
switcher (top left) — OpenAI's `gpt-5.4-mini` or a local `llama3.2` via Ollama.

Every answer is scored for faithfulness and relevance, and 👍/👎 on any answer feeds back
into that scoring. Type `/dashboard` any time to see usage and quality charts.
